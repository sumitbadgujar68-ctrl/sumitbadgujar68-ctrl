## ⚡ The Engineering Manifesto

I operate as a **Forward Deployed Engineer (FDE)** and **High-Velocity Systems Builder**. I sit at the exact fault line where bleeding-edge AI models collide with unyielding production constraints. While others write pitch decks or play with playground prompts, I architect and ship end-to-end software: resilient async backends, graph-based distributed state machines, real-time voice loops, and reactive web applications that don't crumble under real traffic.

I don't believe in silos. A real Forward Deployed Engineer owns the full lifecycle:
- **Architecting** the data persistence layers (PostgreSQL schemas, async connection pools, vector indices, SQLite FTS5 stores).
- **Engineering** high-throughput backend APIs with strict schema validation (FastAPI, WebSockets, Pydantic, Node.js).
- **Crafting** polished, responsive, and accessible client interfaces (React 19, TypeScript, Tailwind CSS v4, Framer Motion, shadcn/ui).
- **Wiring** autonomous LLM agents with multi-step planning, tool-use execution, and deterministic fallback loops.
- **Containerizing & Deploying** horizontally scalable workloads from day zero.

When I’m not building flagship projects from an empty repository, I’m digging through the source code of complex open-source frameworks—auditing their memory models, benchmarking their inference speeds, and contributing back to the global developer ecosystem.
