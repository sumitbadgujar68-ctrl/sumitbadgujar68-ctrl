### 🤖 JARVIS — Voice-First AI Assistant

An MCU-inspired **voice-first AI assistant** that runs on macOS — talk to it, and it talks back with a British accent, dry wit, and an **audio-reactive Three.js particle orb** that pulses in sync with its voice. This is not a chatbot wrapper — it's a full system that integrates with Apple Calendar, Mail, and Notes via AppleScript, spawns **Claude Code sessions** to build entire software projects through voice commands, browses the web via Playwright automation, and maintains persistent memory using SQLite with FTS5 full-text search.

The architecture is a real-time voice loop: **Microphone → Web Speech API → WebSocket → FastAPI → Claude Haiku (fast) / Opus (deep) → Fish Audio TTS → WebSocket → Speaker**. The backend is a ~2300-line FastAPI server handling WebSocket JSON + binary audio streams, while the frontend is a Vite + TypeScript app with a stunning Three.js particle visualization. Features an action system with tagged intents (`[ACTION:BUILD]`, `[ACTION:BROWSE]`, `[ACTION:RESEARCH]`), multi-step task planning, and proactive background task notifications.

`Python` `FastAPI` `WebSockets` `Anthropic Claude` `Fish Audio TTS` `Playwright` `Three.js` `Vite` `TypeScript` `SQLite` `AppleScript`

### 🎬 SkyReels-V2 — Infinite-Length Film Generation

A cutting-edge **generative AI model for infinite-length video synthesis**. This project represents the frontier of AI-generated cinema — using diffusion-based pipelines to generate arbitrarily long, coherent video sequences with consistent temporal dynamics.

The stack is pure deep learning infrastructure: **PyTorch** with **Flash Attention** for memory-efficient self-attention, **Hugging Face Diffusers** for the diffusion pipeline, **Transformers** for the backbone architecture, **Accelerate** for multi-GPU distributed training and inference, and **xFuser** for parallelized inference across GPU clusters. The system also includes **SkyCaptioner v1** for automatic video captioning. I'm contributing to and studying this project to deepen my understanding of generative video models, diffusion architectures, and large-scale GPU inference optimization.

`Python` `PyTorch` `Diffusers` `Transformers` `Accelerate` `Flash Attention` `xFuser` `OpenCV` `CUDA`

### 🪀 Pinokio — AI Browser & Universal App Launcher

A **one-click launcher for any open-source AI project** — think of it as a user-friendly terminal wrapped in an Electron desktop app that can programmatically download, install, configure, and run any AI tool with zero manual setup. It manages isolated environments (Conda, pip, npm), handles GPU dependencies, and provides a visual UI for launching everything from Stable Diffusion to LLM chat interfaces.

Built on **Electron** with electron-builder for cross-platform distribution (macOS, Windows, Linux), electron-store for persistent configuration, and auto-update capabilities. The script system uses a custom JSON-based DSL for declarative app installation with built-in security guarantees: sandboxed execution paths, virtual environment isolation, and a rigorous script verification process. I'm exploring Pinokio's architecture to understand desktop AI application distribution patterns.

### 📚 PocketFlow — Codebase to Tutorial Generator

An **AI agent that crawls entire GitHub repositories** and automatically generates beginner-friendly tutorials with clear visualizations explaining how the code works. This project has generated tutorials for major open-source projects including FastAPI, NumPy, Flask, LangGraph, DSPy, and AutoGen — and reached the **Hacker News front page** with 900+ upvotes.
